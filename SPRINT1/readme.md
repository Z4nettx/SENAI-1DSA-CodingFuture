# 📄 Projeto – Telas do Sistema

Este repositório contém as **telas estáticas** desenvolvidas pela equipe **CodingFuture** para um sistema web.  
As telas foram criadas utilizando **HTML e CSS**, são **responsivas para mobile** e possuem um **protótipo no Figma** para referência visual.  

## 📱 Telas Disponíveis

- **Página Principal**  
- **Painel de Administração**  
- **Tela de Login**  
- **Cadastro de Produtos**  
- **Cadastro de Fornecedores**  
- **Listagem de Produtos**  

## 🛠 Tecnologias Utilizadas

- **HTML5**  
- **CSS3**
